# Professional services (conformance pack)

This pack exists to prove that N-Perform's core is **institution-agnostic**.
It uses a materially different policy from the charging equipment-sales pack:
professional-services project margin, a lower cash weight, no after-sales
reserve and no channel split. The core does not change; only policy data and
fixtures do.

If this pack requires core changes, the abstraction is wrong. Add a generic
calculator or DSL primitive instead of branching on an industry.
